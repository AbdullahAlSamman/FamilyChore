# Desktop App Module (:app:desktopApp)

## Purpose
The platform-specific entry point for the Desktop (JVM) application. It handles window management and Desktop-specific assets.

## Dependencies
- `:app:shared`: Shared business and UI logic.
- **Compose Multiplatform (Desktop)**: UI rendering for JVM.

## Consumers
- None (Final binary).

## Testing
- Desktop-specific JVM tests.
